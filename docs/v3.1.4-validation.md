# v3.1.4 validation

Validated on Windows, 2026-10-27.

- 119 Python tests passed in the development environment.
- The same 119 tests passed with the packaged Python 3.13 runtime and locked installer dependencies.
- Caption editor JavaScript syntax, timing/highlighting tests, and streaming boundary tests passed.
- Actual FFmpeg renders cover source-position splitting, single-clip speed, mixed silent/audible clips, every supported sequence transition, and all sticker animation choices.
- The current application starts when staged through the older updater allowlist. Updates preserve the pre-activation validation and rollback checks.
- The packaged application starts and reports version 3.1.4 with isolated storage.
- Browser checks cover unapplied-edit export prevention, sequence undo, CPU selection, and a completed rendered preview.
- Cancellation/resumption tests preserve saved captions, retain completed karaoke work separately, and reject stale recovery data after edits.
- Font tests cover successful serving, rejected replacement, and preservation of existing bytes.

Coverage.py measured approximately 65% across the selected application modules: captions 85%, composition 86%, updater 93%, encoder helper 80%. This is not a claim of 100% coverage or a measurement of every repository file. Application routes and external-service integrations need more coverage.

The installer was compiled and its runtime tested. A destructive replacement of an existing real installation was not used as a test. Live provider downloads, every GPU/driver combination, and singing-alignment accuracy on representative real songs were not exhaustively verified. Live preview can still approximate some effects; use the rendered check for export appearance.

See [remaining work](stability-roadmap.md). Original media and real caption projects were not used as test fixtures.
